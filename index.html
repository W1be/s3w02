Заголовки

Заголовки на сайте могут быть разных уровней, начиная от заголовка первого уровня (H1) и заканчивая заголовками шестого уровня (H6). Использование заголовков является семантически верным, так как позволяет структурировать содержимое страницы и указать наиболее важные разделы.

Браузеры и поисковые системы используют семантическую верстку для более эффективного индексирования страниц и повышения их релевантности для пользователей. Кроме того, использование заголовков упрощает доступ к информации для людей с ограниченными возможностями, таких как слабовидящие или незрячие пользователи, которые могут использовать программы чтения экрана для навигации по сайту.

Списки

Каждый элемент списка создается с помощью тега li. Теги ol (Ordered List, упорядоченный, нумерованный список), ul (Unordered List, неупорядоченный, маркированный список) и dl (Description List, Список описаний) используются для создания основных типов списков. Каждый элемент списка создается с помощью тега li.

Таблицы

В HTML таблицы создаются с помощью тега table. Внутри тега table располагаются строки таблицы, которые создаются с помощью тега tr. Внутри каждой строки располагаются ячейки таблицы, которые создаются с помощью тега td. Также можно использовать теги th для создания заголовков таблицы. Заголовки могут располагаться как в первой строке таблицы, так и над таблицей, в этом случае используется тег caption.

Изображения

В HTML можно создавать картинки с помощью тега img. Этот тег имеет атрибут src, который указывает путь к изображению. Атрибут alt задает текст, который будет отображаться вместо картинки, если она не загрузится или пользователь использует программу чтения экрана.

Ссылки

В HTML ссылки создаются с помощью тега a. Чтобы создать ссылку, нужно указать атрибут href, который содержит адрес страницы, на которую должна вести ссылка. Также можно добавлять атрибут target, чтобы указать, как должна быть открыта страница, на которую ведет ссылка. target="_blank" откроет ссылку в новой вкладке.
